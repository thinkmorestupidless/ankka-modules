# spec-001-goldvibe

`plan.json` is what spec 001's brands tool rendered for goldvibe: the descriptors, the exposed
services, the topics and the grants made and received, from `brands/goldvibe/manifest.json` as it
stood at e9e3418 (the parent of the rename to `tools/modules`, byte for byte the same document as
`tests/fixtures/manifests/goldvibe.json`) against the `dev-kind` installation. It was generated once
with that tool's `Render.plan`, unchanged since but for its package, and is not regenerated:
`RenderSuite` holds spec 021's rendering of goldvibe's values to it (SC-001).
