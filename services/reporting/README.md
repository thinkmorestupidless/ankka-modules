# reporting

A brand's reports (spec 015): the revenue report, the dashboard, the player report and the ledger, the
bonus and provider reports, the dispute report, the day-end with its reconciliation, the compliance
exports and the prediction-market reports. Every figure is a fold of the brand's facts.

An ankka 0.16 service in Scala, one sbt build. The components, the suites and how to run it are written
as the service is built (spec 015 T072).
