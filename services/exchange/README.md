# exchange

Spec 023: a brand's order books on the exchange library: the gate and ledger ports onto the brand's services, reads, facts and reconciliation. An ankka 0.14.2 service in Scala, one sbt build, composing
ankka-predictions' `exchange-components` at a pinned version (`PREDICTIONS_VERSION`, default 0.1.0).

The components, routes and suites are written up as the service is built (spec 023 T045).
